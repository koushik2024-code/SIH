# Studio release changes

This release adds `app/languages.py`, `app/media.py`, `app/revisions.py`,
`app/publishing.py`, `app/limits.py`, `app/api/publishing.py`,
`tests/test_studio.py` and `docs/STUDIO_SETUP.md`.

- New responsive light/dark dashboard with source tabs, format cards, language
  and image controls, manual editor/live preview, AI revision dialog, connection
  forms, exact-payload publishing preview, and history search/filter/bulk selection.
- Wikimedia raster retrieval with metadata license screening, bounded downloads,
  attribution overlays and local/card fallback. Internal-mode egress controls.
- Seventeen text language choices; voice language metadata checks and configurable
  language-to-voice/font maps. Missing voices never silently use English.
- Versioned manual changes and separate configurable lightweight local-model revisions.
- Encrypted per-user LinkedIn/X/SMTP credentials, typed preview tokens, explicit
  submit, deduplication, thread checkpoints and partial/unknown status receipts.
- Atomic ownership checks for selected deletion, file cleanup and unused-source deletion.
- Per-process local-model backpressure and updated security/setup documentation.

See VALIDATION.md for current test counts and unverified components. Historical
change records below describe earlier versions, not current feature limitations.

## Major fixes

- Replaced SQLite keyword matching with local Qdrant semantic retrieval, including tenant/source filters and optional local reranking.
- Added metadata-aware evidence creation, DIRECT citations and route preview with the editable topic query.
- Added strict format schemas and one validation repair; rejected invented citations and empty/cross-format output.
- Separated access/citation JWT types, required a secure signing key and added audits and request safeguards.
- Pinned URL network connections to validated public IPs; prevented redirects and bounded response size.
- Replaced repeated asset filenames with unique files and restored readable history and refreshed citation links.
- Composed videos from local narration WAV lengths, reviewed local media or caption cards, with temporary-file cleanup.
- Rebuilt the frontend around source selection, route preview, readable output formats, copies/downloads and video preview.
- Added reproducible Windows setup, tested module entrypoints, local model provisioning instructions and regression coverage.
